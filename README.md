# วัชรินทร์โกลด์ — Gold Melt Log (เว็บของตัวเอง)

เวอร์ชันสแตนด์อโลน ไม่ได้รันอยู่ใน Claude อีกต่อไป จึงไม่มีปัญหา storage พัง หรือ CSP บล็อกการเชื่อมต่อ Google Sheet แบบที่เจอตอนใช้ในแชท

## ความแตกต่างจากเวอร์ชันในแชท Claude

| ฟีเจอร์ | ในแชท Claude | เว็บของตัวเอง |
|---|---|---|
| บันทึกถาวร | มีบั๊ก (Unexpected response type) | localStorage ของเบราว์เซอร์ ใช้ได้เสถียร |
| ส่งเข้า Google Sheet อัตโนมัติ | ❌ ถูก CSP บล็อก | ✅ ใช้ได้ |
| AI สแกนบัตร/อ่านตาชั่ง | ✅ ฟรี (ผ่านระบบพิเศษของ Claude) | ต้องใส่ Anthropic API key ของตัวเอง (มีค่าใช้จ่าย) |
| ถ่าย/อัปโหลดรูป, คัดลอกไปวาง Sheet, แชร์ LINE | ✅ | ✅ |

## ขั้นตอนติดตั้ง (ทำครั้งเดียว บนคอมพิวเตอร์)

### 1. ทดสอบรันในเครื่องก่อน (ไม่บังคับ)

```bash
cd gold-melt-log-app
npm install
npm run dev
```

เปิด http://localhost:5173 ดู ถ้าหน้าตาเหมือนในแชท Claude แปลว่าใช้ได้

### 2. อัปโหลดขึ้น GitHub

1. สร้างบัญชี GitHub ที่ github.com (ถ้ายังไม่มี)
2. สร้าง repository ใหม่ (New repository) ตั้งชื่ออะไรก็ได้ เช่น `gold-melt-log`
3. อัปโหลดโฟลเดอร์นี้ทั้งหมดขึ้นไป — ถ้าไม่คุ้นเคยกับ git ใช้วิธีลากไฟล์วางในหน้าเว็บ GitHub ได้เลย (Add file > Upload files)

### 3. Deploy ขึ้น Vercel (ฟรี)

1. ไปที่ https://vercel.com → สมัครสมาชิกด้วยบัญชี GitHub (กด "Continue with GitHub")
2. กด **Add New... > Project**
3. เลือก repository `gold-melt-log` ที่เพิ่งอัปโหลด
4. Vercel จะตรวจพบว่าเป็นโปรเจกต์ Vite อัตโนมัติ ไม่ต้องแก้ค่าอะไร กด **Deploy**
5. รอสักครู่ จะได้ลิงก์เว็บถาวร เช่น `https://gold-melt-log.vercel.app`

ทุกครั้งที่แก้โค้ดแล้วอัปโหลดขึ้น GitHub ใหม่ Vercel จะ deploy เวอร์ชันใหม่ให้อัตโนมัติ

### 4. ใช้งานจากมือถือ

1. เปิดลิงก์ Vercel ที่ได้ใน Safari (iPhone) หรือ Chrome (Android)
2. กด Share (ไอคอนสี่เหลี่ยมมีลูกศรชี้ขึ้น) → **Add to Home Screen**
3. จะได้ไอคอนแอปขึ้นหน้าจอ กดเปิดได้ทันทีเหมือนแอปจริง

## ตั้งค่าเพิ่มเติมในแอป (กดไอคอนเฟือง ⚙️)

- **Anthropic API key** (ไม่บังคับ) — ใส่เพื่อเปิดใช้ฟีเจอร์ AI สแกนบัตร/อ่านตาชั่ง สร้างคีย์ได้ที่ console.anthropic.com คีย์นี้เก็บไว้ใน localStorage ของเบราว์เซอร์เครื่องนั้นเท่านั้น (ไม่ได้ส่งไปที่ไหนอื่นนอกจาก Anthropic ตอนเรียกใช้ AI)
- **Google Sheet URL** (ไม่บังคับ) — ใช้ไฟล์ `google-sheet-code.gs` ที่ให้ไว้ก่อนหน้าตั้งค่า Apps Script ตามปกติ แล้ววาง URL ที่ได้ลงตรงนี้

## ข้อควรระวังเรื่อง API key

ฟีเจอร์ AI เรียก Anthropic API ตรงจากเบราว์เซอร์ (ไม่ผ่านเซิร์ฟเวอร์ตัวกลาง) เพื่อความง่าย วิธีนี้เหมาะกับการใช้งานคนเดียว/ในทีมที่ไว้ใจกันเท่านั้น **อย่าแชร์ลิงก์เว็บนี้ให้คนแปลกหน้า** เพราะถ้าเขาเปิด Developer Tools จะเห็นคีย์ที่ใส่ไว้ได้ (คีย์เก็บอยู่ในเบราว์เซอร์ของคนที่ใส่เอง ไม่ได้ฝังอยู่ในโค้ดที่ deploy จึงไม่มีใครเห็นได้นอกจากคนที่ใส่คีย์ในเครื่องนั้นเอง — แต่ถ้าใครยืมเครื่อง/เบราว์เซอร์ที่ตั้งค่าไว้แล้วไปใช้ ก็จะใช้คีย์นั้นเรียก AI ได้ด้วย)

## ข้อจำกัดของ localStorage

ข้อมูลจะอยู่ถาวรในเบราว์เซอร์/เครื่องนั้นเท่านั้น ไม่ sync ข้ามอุปกรณ์ ถ้าอยากดูข้อมูลรวมจากหลายเครื่อง ให้ตั้งค่า Google Sheet ไว้ด้วย จะได้มีที่เก็บกลางที่ทุกเครื่องเห็นตรงกัน
